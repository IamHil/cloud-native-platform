# Cloud Native Platform

## Goal

Build a production-style cloud-native application using AWS services locally with LocalStack.

The objective is to learn:

- AWS Core Services
- Infrastructure as Code
- Docker
- CI/CD
- Kubernetes
- Monitoring & Logging
- Cloud Architecture
- DevOps Practices

without incurring AWS costs.
